PROMPTING TIPS

Give the AI a concrete job.

  1. Supply context. Attach the requirements, relevant code, and component docs.
  2. Name one user story. State the Sprint Goal and what already works.
  3. Define done. Include constraints, acceptance criteria, and the output you expect.
  4. Request evidence. Ask for runnable changes, setup steps, and actual test outcomes.
  5. Iterate with observations. Bring back errors, logs, screenshots, and hardware behavior.
Example: implement the tap interaction
Use the attached WakeQuest context, current code, and Elegoo component docs.

Sprint Goal: Enable users to dismiss an alarm from across the room so we can test whether the interaction helps them get out of bed.

Hardware: ESP32-WROOM-32D, Elegoo Tap Module, and Seven-Color Flash Module. Use a verified 3.3 V-compatible input. The switch detects a tap; it cannot verify lifting.

Acceptance criteria: accept a tap only during an active alarm; stop sound and disable the indicator; complete the session once; debounce repeated switch signals; ignore stale events.
